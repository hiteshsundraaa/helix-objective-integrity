# Claim Boundaries

HELIX makes narrow, testable claims.

## Supported Claims

- Long-horizon agent safety can be evaluated as a trajectory-level objective-integrity problem.
- External contract-bound gating is useful when internal self-certification may share a corrupted reference frame.
- Constraint survival, authority divergence, forbidden action pressure, contradiction pressure, and objective curvature are useful diagnostic metrics.
- Gate value must be shown against hostile baselines, especially matched-friction random blocking.

## Unsupported Claims

HELIX does not claim to prevent all prompt injection or jailbreak attacks, guarantee production safety for all agent systems, replace sandboxing/identity/authorization/human review, or provide calibrated probabilistic risk estimates in v0.1.
