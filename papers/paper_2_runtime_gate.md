# External Contract-Bound Gating for Non-Deterministic Agent Tool Execution

## Thesis

A long-horizon agent should not be allowed to execute consequential tools merely because the next action appears locally valid. The runtime must verify that the current objective state remains inside the original signed contract boundary.

## Focus

- pre-tool-call verification;
- allow/warn/degrade/quarantine/block decisions;
- reason-coded receipts;
- self-certification failure;
- allowlist-only baseline failure;
- matched-friction random blocking.
